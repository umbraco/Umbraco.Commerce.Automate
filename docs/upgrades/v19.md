# Upgrade to Umbraco 19

From `18.0.0` (the CMS version the v18 ranges resolve) to `19.0.0-rc1`.
Branch `release/19.0.0`, cut from `origin/main` at `7d45daf`.

**Targets CMS release:** `19.0.0-rc1`. Its GitHub release is still a draft on 12-11-2026, so
there's no tag yet: source is `release/19.0` at `b158b78`. This is a pre-release, so the
package ships as `19.0.0-beta`, following Automate core's naming.
