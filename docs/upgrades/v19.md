## Decisions

- 12-11-2026: target CMS `19.0.0-rc1`, not beta1. Licenses 19.0.0-beta is gone from MyGet,
  so beta1 can't be restored cleanly. Automate 19.0.0-beta was built on beta1 and runs on rc1
  untested, so the smoke covers it.
- 12-11-2026: `version.json` moves to `19.0.0-beta` in the bump task, not with the other markers.
- 12-11-2026: the v19 work lives on a long-lived line, `v19/dev` (Rick). It started as
  `release/19.0.0` and was renamed before any push: a `release/*` push publishes to MyGet,
  and nothing on the line should publish until a pre-release is cut. Each beta or rc is cut
  from `v19/dev` as `release/YYYY.MM.N` (shared monthly counter) and merged back.
  `azure-pipelines.yml` needs `v19/dev` in its triggers so pushes build (markers task).
- 12-11-2026: Commerce floor is `[19.0.0-rc.1, 19.999.999)`, not `-beta.1`. Commerce replaced
  `19.0.0-beta.1` with `19.0.0-rc.1` on the prereleases feed, and a floor must name a version
  that exists, or the packed nuspec points at a missing package (feature-build, task 1,
  orchestrator).
- 13-11-2026: v19 pre-releases publish to NuGet.org and MyGet (Rick).
- 13-11-2026: the first v19 label is `19.0.0-rc1`, matching Automate core; this replaces the
  `19.0.0-beta` decision (Rick).
- 13-11-2026: release Commerce, Forms, Deploy and UI Builder now; Engage waits for an Engage RC
  (Rick).
- 13-11-2026: the CMS target stays `19.0.0-rc1`: rc2 has no tag or GitHub release yet.
